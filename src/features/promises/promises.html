Promise

"I Promise a Result!"

Promises were created to make asynchronous JavaScript easier to write and read.Promises represents the completion or failure of an asynchronous operation.

A promise can be in one of three states:

pending operation started (not finished)
rejected operation failed
fulfilled operation completed
