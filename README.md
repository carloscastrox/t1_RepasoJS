
# 📘 Proyecto CRUD + Ejercicios JS
### **Estructura Feature-Based | Bootstrap 5 | JavaScript**

Aplicativo web desarrollado para fines educativos como ejercicio de repaso general de **JavaScript**, aplicando conceptos fundamentales como:

- Manipulación del DOM  
- Callbacks  
- Promesas  
- Async/Await  
- Desestructuración de objetos  
- CRUD con LocalStorage  

El proyecto está organizado bajo la arquitectura **Feature-Based**, lo que permite mantener el código modular, escalable y más fácil de mantener.

---

## 🚀 Características principales

### ✔ CRUD de datos  
- Registro, edición y eliminación de información.  
- Almacenamiento en **LocalStorage**.  
- Estilos modernos implementados con **Bootstrap 5**.  

### ✔ Ejercicios de JavaScript incluidos  
Cada concepto tiene su propio módulo dentro de la estructura Feature-Based:

| Feature | Descripción |
|--------|-------------|
| `crud` | Implementación completa del CRUD usando LocalStorage. |
| `callbacks` | Ejemplos sencillos sobre el funcionamiento de callbacks. |
| `promises` | Uso básico de promesas con `.then()` y `.catch()`. |
| `asyncawait` | Ejercicios con funciones asíncronas usando `async` / `await`. |
| `destructuring` | Ejemplos prácticos de desestructuración de objetos. |

## 🎨 Interfaz gráfica

El proyecto utiliza:

- **Bootstrap 5.3.3**
- **Bootstrap Icons**
- Navbar fija en la parte superior
- Paleta oscura para mayor comodidad visual
- Estilos personalizados en `/src/shared/css/styles.css`

## 🧱 Estructura del Proyecto (Feature-Based)

```
/public
  └── images
      └── logosena.png
      └── jslogo.png

/src
 └── shared
      └── css
          └── styles.css
 └── features
      ├── crud
      │    └── crud.html
      ├── callbacks
      │    └── callbacks.html
      ├── promises
      │    └── promises.html
      ├── asyncawait
      │    └── asyncawait.html
      └── destructuring
           └── destructuring.html

index.html
```

Cada *feature* contiene su propia vista, script y recursos necesarios para funcionar de manera independiente.

- Organicen mejor sus proyectos

- Dominen diferentes técnicas de asincronía
